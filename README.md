# Практическая работа №2

## Вариант 3. Проверка характеристик числа

Консольная программа на Python для анализа целых чисел.

### Возможности программы

- Определение знака числа.
- Проверка чётности.
- Проверка делимости на 3 и 5.
- Проверка простого числа.
- Подсчёт количества цифр.
- Проверка, является ли число полным квадратом.
- Возможность анализировать несколько чисел подряд.
- Обработка некорректного ввода.

### Запуск

Запустить файл `number_check.py` в Python.
